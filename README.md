# Customer-Shopping-Behavior-Analysis

## 📋 Overview
This project delivers a complete end-to-end data analytics pipeline designed to clean raw consumer data, explore key behavior patterns using SQL, and build an interactive performance-tracking dashboard in Power BI. 

By handling data transformation in Python, relational mapping and deep-dive querying in SQL, and stakeholder-ready visualization in Power BI, this repository replicates a realistic corporate business intelligence lifecycle. The final outputs have been synthesized into a comprehensive business report to deliver actionable recommendations.

## 📊 Dataset Summary

Customer metric dataset
  
**Rows:** 3,900

**Columns:** 18

**Description:** Tracks consumer transactional variables, demographic dimensions, promotional triggers, and performance ratings.

**Key Features:**
      Customer demographics (Age, Gender, Location, Subscription Status), 
      Purchase details (Item Purchased, Category, Purchase Amount, Season, Size, Color), 
      Shopping behavior (Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type)

**Missing Data:** 37 values in Review Rating column

## 🛠️ Tools & Technologies

**Data Processing & Engineering:** Python (Pandas & NumPy) via 🪐 **Jupyter Notebook** & 📦 **Anaconda**

**Database Management:** SQL (Relational Database Analysis & Deep-Dive Queries)

**Business Intelligence & Visualization:** Power BI Desktop (DAX Modeling & Interactive Dashboards)

## 🔄 Project Architecture & Workflow
The project was executed in three distinct phases to ensure data integrity and deep analytical depth:

Phase 1: Data Preprocessing and Cleaning using Python.

Phase 2: Structural Data Exploration and In-depth Analysis using SQL.

Phase 3: Interactive Dashboard Development and Reporting via Power BI.

## 🐍 Python Preprocessing Pipeline
The raw customer data was transformed into a structured, analysis-ready format through the following steps.

#### 1. Ingestion & Exploratory Data Analysis (EDA)
* Loaded the raw customer dataset using **Pandas**.
* Inspected structural features via `.head()` and isolated data formats, column types, and missing records with `.info()`.

#### 2. Data Preprocessing & Cleaning (Python)
* **Imputed Missing Features:** Handled missing rows in the `Review rating` column by replacing null values with the column's median review rating to preserve statistical accuracy.
* **Schema Standardization:** Programmatically renamed all column metrics to a clean, uniform format using lowercase strings and underscores (`_`) to guarantee database alignment.

* **Data Transformation and Enrichment:** 
  * Grouped the continuous `age` field into clear demographic buckets (`age_group`) using Pandas `qcut` combined with custom string category labels.
  
  <img width="369" height="372" alt="image" src="https://github.com/user-attachments/assets/3855974d-ab37-4580-a748-ee82b3cbe6cd" />

  * Standardized the string-based `frequency_of_purchases` descriptions into exact numeric day counts for quantitative aggregation.
* **Deduplication:** Dropped the redundant `promo_code` column after verifying it contained data duplicate to the `discount_code_applied` column, minimizing data redundancy and file footprint.

## 🖥️ Interactive Dashboard (Power BI)

A clean, interactive "Customer Shopping Behaviour Dashboard" was built to turn this raw data into clear visual stories across five key areas:

* **Key Performance Indicators (KPIs):** Displays the main business health stats at a single glance, showing 4,000 total customers, an average spend of $59.76, and a 3.75 out of 5 average review rating.
* **Subscription Breakdown:** Uses a clear donut chart to show loyalty splits, proving that the vast majority of shoppers are non-subscribers (73% or 2.85K) compared to active subscribers (27% or 1.05K).
* **Category Performance:** Uses vertical bar charts to easily compare different product lines, revealing that Clothing brings in the most sales and highest revenue out of all categories.
* **Age Demographics:** Uses horizontal bar charts to track spending against our custom age groups, clearly pinpointing "Young Adults" as our most profitable customer group.
* **Interactive Filters (Slicers):** Includes an easy-to-use left sidebar menu where anyone can instantly filter all the charts by Subscription Status, Gender, Category, or Shipping Type with one click.

## 💡 Strategic Business Insights (From Project Report)
By synthesizing the SQL analysis and Power BI visualizations into the final project report, the following data-driven insights were uncovered:

* **Target the "Young Adult" Segment:** Focus marketing budgets on this group as they generate your highest overall revenue.
* **Convert Non-Subscribers:** Launch sign-up perks targeting the 73% non-subscriber majority to quickly grow recurring revenue.
* **Bundle with Clothing:** Package lower-performing product categories (Accessories/Footwear) alongside top-selling Clothing items to increase inventory movement.
* **Increase Average Order Value (AOV):** Set a free shipping threshold at $65 or $70 to organically push the current $59.76 average spend baseline higher.

## 🚀 How to Run

### Prerequisites
Ensure your machine has the following tools configured:
* Python 3.x (with Pandas library installed)
* SQL Database Instance (e.g., MySQL, PostgreSQL, or SQL Server)
* Power BI Desktop

### Step-by-Step Execution
1. **Clone the project repository:**
   ```bash
   git clone https://github.com
   cd Customer-shopping-behavior-analysis
   ```
2. **Execute Data Pipelines:** Open your Jupyter or script environment and run your data cleaning sequence:
   ```bash
    `jupyter notebook`
   ```
4. **Run SQL Scripts:** Open your database tool engine, run the setup schema scripts, and execute your analysis queries inside your workspace server layer.
5. **Launch Power BI Visuals:** Double-click the desktop dashboard file located inside your dashboard directory folder to interact with the visual interface layout
